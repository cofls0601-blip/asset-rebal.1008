# Rebalance · 수동 자산배분

규칙 빌더 및 자동 전략 판정을 제거하고 사용자가 직접 계획하는 자산배분 앱입니다.

## 화면

- **이번달**: 전략당 카드 하나, 모바일 1열/PC 2열. 기준일 종가의 원화 환산 평가액과 전략 내 종목 비중.
- **리밸런싱**: 전략명·티커·종목명·보유수량·통화·종가·평가액·현재/목표 비중·10개월 SMA·12개월 수익률. 목표는 직접 입력합니다.
- **주문안**: 보유 또는 후보 종목의 매수/매도 수량을 반영합니다. 새 종목은 검색하여 후보로 등록한 뒤 매수합니다.
- **기록**: 평가 스냅샷을 확정하고 각 시트를 CSV/TSV로 출력합니다.
- **설정**: 전략 추가/변경/삭제, 종목 검색/추가/삭제, 최종 보유수량과 목표비중 입력, CSV/백업 복원.

## GitHub에 업로드

1. 새 저장소를 만들고 ZIP을 압축 해제합니다.
2. `asset-rebalance-manual` 폴더 **안의 파일과 하위 폴더**를 저장소 루트에 업로드합니다. ZIP 자체를 코드로 업로드하지 마세요.
3. Streamlit Community Cloud에서 저장소와 `streamlit_app.py`를 선택합니다.
4. 기존 앱의 Secrets를 새 앱에 설정합니다. 비밀번호/시크릿은 저장소에 커밋하지 마세요.

## 실행

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 관리 규칙

전략 추가 시 원화 현금(CASH) 항목이 생성됩니다. 후보는 수량 0으로 추가합니다. 중복 전략과 중복 종목은 차단합니다. 국내 수량은 정수, 미국 수량은 소수점 입력이 가능합니다. 음수와 비정상 숫자를 차단하고 목표비중은 0~100%로 제한합니다.

설정에서는 작성 중인 목표 합계가 100%가 아니어도 저장하고 경고합니다. 리밸런싱 화면의 최종 목표 적용은 합계 100%를 요구합니다. 보유 자산이 있는 종목/전략은 수량과 현금을 0으로 정리한 뒤 삭제합니다. 전략명 변경과 삭제는 과거 기록을 변경하지 않습니다.

**설정의 보유수량**은 최종 잔고이고, **주문안의 매매수량**은 잔고에 더하거나 뺄 수량입니다. 앱은 실제 증권 주문을 전송하지 않습니다. CASH는 거래대금으로 자동 조정하지 않으며 실제 원화 잔액을 직접 입력합니다. 가격/수량 변경 후 종가를 다시 조회하세요.

## 가격과 검색

기준일 이전 마지막 종가와 원/달러 환율을 사용합니다. 7일 초과된 가격은 오류로 표시하며 일부 가격이 없으면 전략 총액과 비중을 확정하지 않습니다. 종가/SMA는 거래통화, 평가액은 원화입니다. 지표는 완료된 월의 비수정 월말 종가로 계산합니다. 월중에는 당월을 제외하고 충분한 월별 자료가 없으면 지표를 비웁니다.

미국 종목명/티커는 Yahoo 검색, 국내 한글 종목명/티커는 KRX 목록 검색도 사용합니다. 서비스 연결이나 검색 결과가 없을 때 직접 입력할 수 있습니다. `.KQ` 티커는 유지해 코스닥을 조회합니다. 검색 응답과 실제 시세 조회는 외부 서비스 상태에 따라 달라집니다.

## Google Sheets

`apps_script/Code.gs`는 원본과 동일합니다. 설정은 `docs/SHEETS_SETUP.md`를 참고하세요. `SHEETS_WEBAPP_URL`, `SHEETS_SECRET`, `APP_PASSWORD`를 Streamlit Secrets에 지정합니다. 기존 원장 형식/8개 탭, 저장 충돌 확인과 저장 후 재조회 검증을 유지합니다. Strategies의 과거 규칙은 호환용 데이터이며 실행하지 않습니다.
